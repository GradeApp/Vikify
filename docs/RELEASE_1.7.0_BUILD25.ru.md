## Резервная копия и изменения

До изменений создана `backups/diagnostics-before-20261126/`: рабочее дерево,
Git bundles, патчи и состояния репозиториев, сведения о выпусках, APK и
исходники стабильной версии. Размеры и SHA-256 всех **14 файлов** из манифеста
повторно проверены: совпадают. Исторические отчёты и артефакты не заменены.

Добавлена диагностика EN/RU с объяснениями и следующими действиями: формат
профиля, ответ подписки, адрес сервера, TCP, HTTPS через выбранный прокси и
отдельно непроверенный трафик других приложений. Прямые проверки требуют
явного, изначально выключенного разрешения; прямого повтора после ошибки
прокси нет. Проверка не меняет сохранённую подписку, выбор профиля и VPN-сеанс.

TXT/JSON формируются из заданных кодов и ограниченных чисел, без реквизитов,
имён профилей, адресов серверов, журналов и исходных сообщений исключений.
Передача — только после предпросмотра по кнопке и выбору получателя Android,
без автоматической отправки. Кэш ограничен восемью файлами; файлы возрастом
от часа удаляются при следующем запуске/передаче. Обновлены встроенные
политики, руководства, README, инвентарь данных и changelog.
[Подробное поведение](DIAGNOSTICS.md).

## Исправленные ошибки

| Проблема | Исправление |
|---|---|
| Числовой IPv4/IPv6 ошибочно проходил DNS-разрешение | Локальный разбор через `InetAddress.getByAddress`, без DNS-запроса |
| После пустого/неудачного DNS показывался ложный `TCP_FAILED` | TCP только после успешного получения непустых адресов; иначе `NOT_TESTED` с исходной причиной `DNS_FAILED`/`OFFLINE` |
| Сбой чтения тела после HTTP 200 ошибочно означал недоступность TCP | Отдельный `NETWORK_IO_FAILED`; DNS, TLS и тайм-ауты сохраняют собственные коды |
| `clearCapabilities()` требовал API 30 | Совместимые с API 21 `removeCapability`, min API 26 сохранён |
| Отмена теряла код, неожиданный сбой выглядел остановкой | Раздельные `CANCELLED` и `FAIL` / `INTERNAL_ERROR`; доступность кнопки подключения пересчитывается |
| Длинный список и мгновенный результат скрывали действия | Действия перенесены наверх, прокрутка сбрасывается по запуску и отчёту; фон диагностики стал менее прозрачным |
| Инкрементальный Compose давал отличающиеся DEX/baseline profile | Релиз проверяется двумя независимыми чистыми сборками |
| С `apksigner` 36 не проходил перенос подписи F-Droid | Для прежнего ключа закреплён build-tools 34.0.0; target API 36 не менялся |

Для сетевых ошибок выполнены регрессионные тесты. Дополнительно исправлены
QA-сценарии выбора получателя в Samsung и нажатия после прокрутки;
последние изменения QA не меняли основной APK и критерии результатов.

Хеш ZIP исходников записывается только во внешнем `SHA256SUMS`/манифесте
после упаковки: этот отчёт входит в архив и не содержит его собственного хеша.

Встроенный этап Android TUN остаётся `NOT_TESTED` / `TUN_NOT_VERIFIED`:
прохождение трафика другого приложения проверялось отдельным QA-компонентом.
При неподтверждённом владельце/маршруте VPN сетевые проверки блокируются;
на API 26–29 это возможно и при подключённой Vikify. Полнота обнаружения
зависит от сведений Android.

Не заявляются новая полная матрица эмуляторов, независимый сторонний
провайдер, ARM32, физическое устройство с 16-КБ страницами памяти или
длительные испытания энергопотребления. Публикации 1.7.0, облачного CI,
новой заявки F-Droid и синхронизации политики на публичном сайте не было.
