# Политика конфиденциальности · Vikify VPN

Редакция от 26 ноября 2026 года. Издатель Vikify VPN — VictoriaV. Применяется к клиенту `vikify.vpn`, включая версию 1.7.0 (код 25) с диагностикой по запросу и передачей отчёта по выбору пользователя. Политика открывается из «Помощи» и с экрана согласия. Доступны встроенный текст и кнопка сайта издателя. [Публичная политика](https://94043.net/vikify/privacy.html). Этот файл и встроенные страницы содержат обновлённый текст; публикация той же редакции на сайте выполняется отдельно.

## Обрабатываемые данные

При нажатии «Вставить» Vikify читает один элемент системного буфера. При выборе QR-кода кадры камеры или выбранное изображение обрабатываются на телефоне. После распознавания приложение показывает домен. Загрузка подписки с указанного сервера начинается после подтверждения пользователем. Кадры камеры и копии выбранных изображений приложение не сохраняет.

Пользователь вводит HTTPS-ссылку подписки. Она содержит токен доступа и отправляется указанному пользователем серверу при загрузке профилей. Ссылка, полученные UUID, параметры профилей, выбор профиля и время обновления хранятся в зашифрованных настройках приложения.

Сохранённый UUID из предыдущей версии используется для совместимости до перехода на подписку. Приложение загружает профили вручную, при возвращении на экран после устаревания данных и по фоновому расписанию Android примерно раз в сутки.

Параметры подключения передаются локальному Xray через память. Версия 1.4 удаляет остаточный файл старой версии при запуске. Перед первым подключением Vikify объясняет обработку трафика и сохраняет версию принятого согласия в приватных настройках. Отзыв согласия в «Помощи» отключает VPN.

## Сетевые соединения

Трафик VPN проходит через выбранный профиль. Само приложение исключено из Android-туннеля, чтобы соединения Xray и загрузка подписки могли использовать базовую сеть.

Для проверки связи выполняется HTTPS-запрос через выбранный прокси к `www.gstatic.com/generate_204`. Если он неуспешен, используется `cp.cloudflare.com/generate_204`. Проверки выполняются перед созданием VPN, при смене сети и примерно раз в минуту. Эти серверы получают запрос с адреса выхода прокси. Токен подписки и UUID не включаются в HTTP-запрос проверки.

Обработку данных на сервере подписки и VPN определяет оператор соответствующей инфраструктуры. Аналитические и рекламные SDK в клиент не включены. Вывод Xray отбрасывается. Пользовательские ошибки и уведомления используют сообщения без токенов и полного конфигурационного файла.

При открытии списка профилей и по кнопке «Проверить» выполняются короткие TCP-соединения с адресами и портами из подписки через базовую сеть. Серверы видят исходный IP и время соединения, DNS-служба сети может получить доменные имена. Прикладные данные, UUID и токен не передаются. Результаты хранятся только в памяти одну минуту, сбрасываются при смене сети. Проверки прекращаются при уходе приложения с экрана. Цвет не гарантирует работоспособность протокола или авторизации.

## Диагностика по запросу

Экран «Диагностика» запускает проверки только по явной кнопке. Проверка формата профиля локальная. Если выбранный профиль уже подключён, загрузка подписки для анализа и HTTPS-проверки идут через локальный SOCKS-прокси текущего сеанса. HTTPS-проверки используют `https://www.gstatic.com/generate_204` и при необходимости `https://cp.cloudflare.com/generate_204`; переход на прямой маршрут при неудаче не выполняется. Эти узлы видят адрес выхода прокси. Токен и UUID в HTTPS-запросы проверки связи не включаются.

Разрешение прямых проверок изначально выключено и сбрасывается при закрытии экрана. Явное включение разрешает DNS-запросы и короткие TCP-соединения к выбранному серверу через базовую сеть. Если выбранный профиль не подключён, оно также разрешает HTTPS-запрос к серверу подписки, включая токен в её URL. DNS-служба сети может видеть доменное имя, серверы — исходный IP и время обращения. Прикладные данные при TCP-проверке не передаются. Если Android сообщает о VPN с неподтверждённым владельцем или маршрутом, сетевые проверки блокируются. На API 26–29 владелец VPN недоступен для проверки, поэтому видимая VPN-сеть может блокировать диагностику даже при подключённой Vikify. На API 30 и новее владелец должен подтверждаться как Vikify. Намеренный обход VPN не выполняется; обнаружение зависит от сетей, которые показывает Android.

Полученный ответ подписки анализируется в памяти без сохранения. Диагностика не обновляет сохранённую подписку, не меняет выбор профиля, не включает и не отключает VPN. Отдельная кнопка подключения закрывает диагностику и запускает обычный процесс подключения с действующими согласиями. Обычные обновления подписки и индикация доступности списка профилей описаны выше; разрешение прямых проверок относится только к экрану диагностики.

Успех TCP означает доступность порта, а успех HTTPS через локальный прокси — успешный запрос через этот прокси. Ни один из этих результатов не подтверждает прохождение трафика других приложений через Android TUN. Этот этап явно отмечается как «Не проверено». Недоступные, пропущенные и прерванные проверки не выдаются за успешные.

## Диагностические отчёты

Результаты и предпросмотр хранятся в памяти до закрытия диагностики или завершения процесса. TXT- и JSON-отчёты формируются из разрешённого перечня полей: версия схемы, код версии приложения, уровень API Android, категория протокола, признак завершения, коды этапа, результата, статуса, маршрута и предлагаемого действия, округлённая длительность, код HTTP и количество принятых или пропущенных профилей при наличии. Числа ограничены допустимыми диапазонами, свободный текст не принимается.

Отчёт не содержит URL и токен подписки, UUID, ключи, имена профилей, адреса и порты серверов, SSID, идентификаторы устройства, журналы, исходные ответы сервера или сообщения исключений. Предпросмотр показывает тот же текст, который будет передан.

Файл создаётся в приватном кэше только по кнопке передачи после предпросмотра. Android предлагает выбрать приложение-получатель и выдаёт ему временное разрешение чтения файла. Автоматической загрузки отчётов нет. Правила получателя распространяются на копию, которую он сохранил или отправил. Vikify не может удалить такую внешнюю копию.

Кэш ограничен восемью файлами. Файлы возрастом от одного часа удаляются при следующем запуске приложения или следующей передаче отчёта. Это очистка при использовании, а не гарантия удаления ровно через час. Очистка кэша средствами Android или удаление приложения удаляет локальные файлы отчётов.

## Удаление

Действие «Удалить сохранённый доступ» удаляет локальную подписку, прежний UUID и оставшийся конфигурационный файл, отменяет фоновое обновление и предусматривает отключение работающего VPN. Резервное копирование и перенос данных приложения отключены. Удаление приложения удаляет его локальные данные.
