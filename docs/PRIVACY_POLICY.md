# Политика конфиденциальности · Vikify VPN

Редакция от 5 ноября 2026 года. Издатель Vikify VPN — VictoriaV. Применяется к клиенту `vikify.vpn` версии 1.5. Политика открывается из «Помощи» и с экрана согласия. Доступны встроенный текст и кнопка сайта издателя. [Публичная политика](https://94043.net/vikify/privacy.html)

## Обрабатываемые данные

При нажатии «Вставить» Vikify читает один элемент системного буфера. При выборе QR-кода кадры камеры или выбранное изображение обрабатываются на телефоне. После распознавания приложение показывает домен. Загрузка подписки с указанного сервера начинается после подтверждения пользователем. Кадры камеры и копии выбранных изображений приложение не сохраняет.

Пользователь вводит HTTPS-ссылку подписки. Она содержит токен доступа и отправляется указанному пользователем серверу при загрузке профилей. Ссылка, полученные UUID, параметры профилей, выбор профиля и время обновления хранятся в зашифрованных настройках приложения.

Сохранённый UUID из предыдущей версии используется для совместимости до перехода на подписку. Приложение загружает профили вручную, при возвращении на экран после устаревания данных и по фоновому расписанию Android примерно раз в сутки.

Параметры подключения передаются локальному Xray через память. Версия 1.4 удаляет остаточный файл старой версии при запуске. Перед первым подключением Vikify объясняет обработку трафика и сохраняет версию принятого согласия в приватных настройках. Отзыв согласия в «Помощи» отключает VPN.

## Сетевые соединения

Трафик VPN проходит через выбранный профиль. Само приложение исключено из Android-туннеля, чтобы соединения Xray и загрузка подписки могли использовать базовую сеть.

Для проверки связи выполняется HTTPS-запрос через выбранный прокси к `www.gstatic.com/generate_204`. Если он неуспешен, используется `cp.cloudflare.com/generate_204`. Проверки выполняются перед созданием VPN, при смене сети и примерно раз в минуту. Эти серверы получают запрос с адреса выхода прокси. Токен подписки и UUID не включаются в HTTP-запрос проверки.

Обработку данных на сервере подписки и VPN определяет оператор соответствующей инфраструктуры. Аналитические и рекламные SDK в клиент не включены. Вывод Xray отбрасывается. Пользовательские ошибки и уведомления используют сообщения без токенов и полного конфигурационного файла.

При открытии списка профилей и по кнопке «Проверить» выполняются короткие TCP-соединения с адресами и портами из подписки через базовую сеть. Серверы видят исходный IP и время соединения, DNS-служба сети может получить доменные имена. Прикладные данные, UUID и токен не передаются. Результаты хранятся только в памяти одну минуту, сбрасываются при смене сети. Проверки прекращаются при уходе приложения с экрана. Цвет не гарантирует работоспособность протокола или авторизации.

## Удаление

Действие «Удалить сохранённый доступ» удаляет локальную подписку, прежний UUID и оставшийся конфигурационный файл, отменяет фоновое обновление и предусматривает отключение работающего VPN. Резервное копирование и перенос данных приложения отключены. Удаление приложения удаляет его локальные данные.
