- `release-artifacts/private-symbols/build22/`: R8 mapping и native symbols только для издателя; в публичные архивы не включены.

Постоянный сертификат VikifyOps: `570b4ad5bbe8ab617b8164226b07be21e8011d977bbe7c4e7070a5b1581e37f0`. Обновление APK поверх предыдущего релиза сохраняет данные. Отладочная сборка с другим сертификатом так не обновится. AAB предназначен для обработки магазином, не для установки на телефон.

## Собственный сайт

Целевой каталог: `https://94043.net/vikify/`. Перед развёртыванием сохранить текущую копию каталога; загрузить содержимое website.zip в выделенную папку без удаления других разделов. Проверить анонимную загрузку обеих страниц, политик, APK и SHA-256; сравнить скачанный APK с локальным манифестом. На существующем Next.js-хостинге проверить новые статические пути после штатного обновления серверного приложения.

Прямая установка использует разрешение Android для выбранного браузера/файлового менеджера. Автоматический установщик APK не добавлялся. Кнопка «Обновить» внутри Vikify обновляет подписку, а не приложение. [Документация Android](https://developer.android.com/distribute/marketing-tools/alternative-distribution)

## GitHub Releases

Репозиторий: [GradeApp/Vikify](https://github.com/GradeApp/Vikify). Основная ветка содержит старый Xray-проект. Сценарий `scripts/publish-github-draft.ps1` создаёт отдельную ветку `codex/vikify-1.6.0-build22` с самостоятельной историей из текущего снимка исходников и черновик `vikify-v1.6.0-build22`. Основную ветку он не меняет. Проверки не допускают перезапись существующей ветки/тега, несовпадение SHA-256 и опасные пути в архиве.

По умолчанию сценарий только проверяет локальный комплект. Для создания черновика нужны `-CreateDraft`, GitHub CLI и вход в аккаунт с правом записи. GitHub CLI авторизован владельцем для GradeApp; HTTPS push настроен. Секрет авторизации хранится средствами GitHub CLI и не включается в комплект. Снимок исходников включает `SOURCES.sha256` и ARM64-библиотеки. Ключи, локальные настройки, реальные подписки и артефакты сборки исключены.

После создания черновик нужно просмотреть и отдельно опубликовать. [GitHub Releases](https://docs.github.com/en/repositories/releasing-projects-on-github/about-releases)

## Перед массовым распространением

- Сохранить независимую резервную копию постоянного ключа и проверить восстановление пароля. Резервная копия проекта не заменяет резервную копию ключа.
- Для выбранных стран проверить регистрацию разработчика и пакета в Android Developer Console/Play Console. Индивидуальный аккаунт сам по себе не препятствует раздаче APK через сайт; Android developer verification проверяется отдельно. [Android developer verification](https://developer.android.com/developer-verification)
- Проверить конкретного стороннего провайдера: поддержаны VLESS TCP REALITY, XHTTP TLS и WebSocket TLS. Другие протоколы/транспорты не заявлены. Доступ к серверу приложение не предоставляет.
- Для публичного F-Droid отдельно подготовить воспроизводимую сборку нативных компонентов; собственный F-Droid-репозиторий потребует сервер и подпись индекса. [Правила F-Droid](https://f-droid.org/en/docs/Inclusion_Policy/) · [Собственный репозиторий](https://f-droid.org/en/docs/Setup_an_F-Droid_App_Repo/)

Google Play отложен по решению владельца. AAB, API 36, согласие на VPN и политика сохранены, но это не означает завершённую верификацию аккаунта, декларации магазина или одобрение модерацией.
