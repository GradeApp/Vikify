# Vikify 1.6.1 build 24 — стабильный выпуск

Дата проверки и перевода в стабильный выпуск: 24 ноября 2026 года.

На сайте 94043.net, в GitHub Releases и в собственном F-Droid-репозитории
распространяется один APK: пакет `vikify.vpn`, версия 1.6.1, versionCode 24,
Android 8.0+, ARM64, target API 36. Опубликованный ранее кандидат переведён в
стабильный выпуск без пересборки, замены тегов, исходного архива или ключей.

Проверены Automatic, Primary, Backup server, Backup 1, Backup 2,
Alternative · XHTTP и Last resort · WebSocket. В каждой сессии независимое
тестовое приложение подтверждало системную VPN-сеть и DNS, HTTPS 204,
загрузку настоящей HTML-страницы по HTTPS и получение внешнего IP через
другой HTTPS-сервис. Всего 14 сессий и 42 проверки трафика.

Телефон уже работал на build 24 до начала этой проверки. Для сохранения
пользовательских данных приложение не удаляли и не понижали версию.
Фактическое обновление build 23 → 24 с сохранением данных проверено
11 ноября и описано в [историческом отчёте](FDROID_MAIN_PREPARATION.ru.md).
Результат 24 ноября не выдаётся за новое обновление 23 → 24.

Ошибок приложения в проведённых сценариях не найдено. После теста смены
ориентации возникло временное отсутствие дерева UI в тестовом скрипте;
исправлен повтор чтения, итоговое состояние проверено отдельно. Android CLI
не смог установить свой старый тестовый компонент из-за Play Protect;
проверка выполнена существующими ADB-сценариями без отключения защиты.
