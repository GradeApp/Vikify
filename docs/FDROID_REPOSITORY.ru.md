# Собственный репозиторий Vikify

Страница добавления: https://94043.net/fdroid/

Адрес репозитория: https://94043.net/fdroid/repo/

SHA-256 сертификата репозитория:

`E55B0EF7D837DF90DC33E2717866C21B31FD4B98681902CEDE0CF75EDF69931C`

Это собственный репозиторий издателя VictoriaV. Он не является основным каталогом F-Droid; приложение не прошло его процедуру включения. Актуальная стабильная версия: Vikify 1.6.1, versionCode 24, ARM64, Android 8.0+. Предыдущий build 23 сохранён в каталоге. Все каналы распространяют один и тот же APK; [проверки](RELEASE_1.6.1_BUILD24.ru.md).

## Установка

Установите официальный F-Droid с https://f-droid.org/. На телефоне откройте страницу добавления и нажмите кнопку либо отсканируйте QR в F-Droid. При ручном добавлении вставьте адрес и сверяйте отпечаток сертификата. После обновления каталога выберите Vikify. Android запросит разрешение установки приложений для F-Droid и подтверждение установки/обновления.

APK подписан постоянным сертификатом приложения `570b4ad5bbe8ab617b8164226b07be21e8011d977bbe7c4e7070a5b1581e37f0`. Он отличается от сертификата репозитория. Установка поверх совместимого релиза сохраняет данные; удаление Vikify не требуется. Отладочные сборки или релизы с другой подписью не подходят для такого обновления.

## Хранение и обслуживание

- Локальное окружение: Ubuntu-24.04 (WSL), `~/vikify-fdroid/venv`, fdroidserver 2.4.5.
- Рабочая папка: `~/vikify-fdroid/work`. `config.yml` и `keystore.p12` имеют режим 0600, родительская папка — 0700.
- Закрытая резервная копия ключа и конфигурации: соседняя папка `VikifyOps/fdroid-private`, доступ Windows ограничен владельцем и SYSTEM. Содержимое нельзя публиковать или коммитить. Независимую офлайн-копию следует хранить отдельно от этого компьютера.
- Публичная папка сервера: `/var/www/vikify-fdroid`. Ключ подписи репозитория на сервер не загружается.
- Разрешённые подписи APK закреплены в `AllowedAPKSigningKeys` метаданных. Приватные подписки и реквизиты не включаются в APK, исходный архив, метаданные или скриншоты.
- Индексы v0/v1/v2 подписаны с современными алгоритмами. Штатный fdroidserver использует SHA-1 для старых форматов; `package-repository.py` переподписывает их современным режимом apksigner, совместимым с Android 8.0+.

## Следующее обновление

1. Увеличить versionCode, собрать APK постоянным ключом приложения и проверить подпись, manifest, контрольную сумму и сохранение данных при обновлении.
2. Подготовить точный публичный снимок исходников и лицензии. Опубликовать новые файлы с новыми именами, не перезаписывая APK уже выпущенной версии.
3. Перенести APK в приватную рабочую папку `repo/`. Обновить `CurrentVersion`, `CurrentVersionCode`, changelog и ссылку на соответствующие исходники. Сценарии первоначального комплекта закреплены за build 23. Для build 24 использован отдельный проверенный комплект; перед следующим выпуском обновить ожидаемую версию и пути, сохранив ключ и прежние APK.
4. Выполнить `fdroid update --pretty`, `fdroid lint`, затем переподпись/проверку и упаковку публичной папки через `scripts/fdroid/package-repository.py`. Не выполнять `fdroid init` повторно: замена ключа изменит доверенную идентичность репозитория.
5. Загрузить только публичный tar и его SHA-256-манифест. `publish-static.py` проверяет каждый файл и заменяет подписанные входные индексы последними. Приватную рабочую папку целиком не синхронизировать.
6. Проверить анонимное скачивание, индексы v1/v2, отпечаток, подпись APK, QR и обновление телефона. При откате переопубликовать индекс с новым временем; Android не понижает установленный versionCode автоматически.

Исходные резервные копии проекта и сайта находятся в `backups/fdroid-before-20261107`; копия nginx и раздела Vikify сохранена также на сервере в `/root/backups/fdroid-before-20261107`.
