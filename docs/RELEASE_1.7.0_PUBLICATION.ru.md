# Vikify 1.7.0 build 25 — публикация

26 ноября 2026 года. **Статус: публикация подготовлена; проверки публичного
доступа ещё не внесены.** Этот локальный документ не подтверждает, что версия
1.7.0 уже доступна во всех каналах. Перед обновлением `main` ответственный за
публикацию заменяет этот статус фактическими результатами таблицы ниже.

Публикуется уже проверенный комплект, пакет `vikify.vpn`, ARM64, Android 8.0+,
target API 36. APK и AAB не пересобираются ради публикации. Подпись приложения
сохранена, обновление поверх прежнего релиза сохраняет подписку и выбор.
[Аудит сборки, диагностики и Galaxy A03s](RELEASE_1.7.0_BUILD25.ru.md) —
отдельный исторический протокол; его утверждение об отсутствии публикации
относится к моменту завершения испытаний.

магазином, а не прямой установки на телефон. Старые опубликованные APK и теги
не перезаписываются. Ключи приложения и репозитория не входят в публичные
файлы и не загружаются на сервер.
