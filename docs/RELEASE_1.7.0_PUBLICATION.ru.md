# Vikify 1.7.0 build 25 — публикация

26 ноября 2026 года. **Vikify 1.7.0 build 25 опубликован на сайте, в GitHub
Releases и собственном F-Droid-репозитории.** Анонимное скачивание и подписи
проверены независимо после развёртывания: 54 загрузки, все успешны.

Опубликован проверенный комплект, пакет `vikify.vpn`, ARM64, Android 8.0+,
target API 36. APK и AAB не пересобирались ради публикации. Подпись приложения
сохранена, обновление поверх прежнего релиза сохраняет подписку и выбор.
[Аудит сборки, диагностики и Galaxy A03s](RELEASE_1.7.0_BUILD25.ru.md) —
отдельный исторический протокол; его утверждение об отсутствии публикации
относится к моменту завершения испытаний.

APK, скачанный из каждого из трёх каналов, совпал с проверенным файлом по
SHA-256 и подтвердил прежний сертификат приложения. `entry.jar`,
`index-v1.jar` и `index.jar` проверены с исходным сертификатом репозитория.
Публичные политики RU/EN побайтово совпали со встроенными в приложение.

Во всех трёх каналах APK один и тот же. AAB предназначен для обработки
магазином, а не прямой установки на телефон. Старые опубликованные APK и теги
не перезаписываются. Ключи приложения и репозитория не входят в публичные
файлы и не загружаются на сервер.

Протоколы развёртывания: `distribution/anonymous-public-verification.json`,
`downloaded-signatures.json` и `deployment-result.json` в локальном комплекте
публикации. Развёрнуто 18 файлов сайта и 31 файл репозитория; конфигурация
nginx и посторонние разделы не изменялись.

и MR-event pipeline [3121379958](https://gitlab.com/GradeApp1/fdroiddata/-/pipelines/3121379958)

приложения. Новый рецепт, его официальный контейнерный прогон, успешный
облачный CI и оценка сопровождающих не подменяются локальными проверками.
Актуальный ход обращения: [fdroid/SUBMISSION.md](../fdroid/SUBMISSION.md).
[Статус CI](FDROID_CI_STATUS.md) ведётся отдельно.
